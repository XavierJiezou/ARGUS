# ARGUS Project Page

A restrained academic project page for **Multi-Agent Forensic Reasoning for Generalizable Deepfake Video Detection**, built from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Contents

- Paper title, authors, affiliations, and local PDF links
- Abstract and contribution summary
- Method and dataset figures
- Out-of-domain result table
- Two frame-level qualitative viewers
- Complete Appendix F prompt library
- BibTeX citation

The project page is published from the repository's `page` branch.
